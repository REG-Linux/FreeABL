FreeABL Flasher

Back up, install and remove FreeABL from your browser. Nothing to install except the USB driver on Windows. Read FLASHING.md and the disclaimer first.

Simulation: no USB device is used. Remove ?sim=1 from the address to flash a real device.

This browser has no WebUSB. Use Chrome, Edge or another Chromium browser on a computer, or the command-line tool freeabl-flash.py.

1. Device and files

  1. Check

    Device in Android? Turn on USB debugging (Settings → About → tap Build number seven times, then Settings → System → Developer options → USB debugging), connect it, and let the page read it and restart it in fastboot mode:

    If your device is not recognised, or you cannot or do not want to turn on USB debugging, boot it to fastboot mode yourself: power it off, then hold the key combination (often Volume Down + Power).

    With the device in fastboot mode:

  2. Back up the stock bootloader

    Boot the device to EDL. The screen stays black in EDL.

    If your device is not recognised, or USB debugging is off: adb reboot edl from a computer, or the device's own way into EDL (a key combination, an EDL cable or a test point: see FLASHING.md).

    The backup downloads as freeabl-backup-SERIAL-androidVERSION-PATCH.tar. Keep it safe: it is the way back to your stock bootloader on this Android build. After an Android update, the flasher makes you back up again: keep the newest one.

    Reads, never writes, every partition of both slots up to 128 MiB (bootloaders, boot, vbmeta…; not your data, not super) into one file of up to a few GB (1.5 GB on an Odin 2 Portal). It holds this device's own data: keep it private.

Windows

    
    
      
  • fastboot: install the Google USB Driver, or any WinUSB driver for the device in fastboot mode.
    • 
      
  • EDL: in EDL the device appears as QUSB__BULK or Qualcomm HS-USB QDLoader 9008 (USB ID 05C6:9008).
        The browser can only reach it through WinUSB: open Zadig, choose Options → List All Devices,
        pick that device, select WinUSB and click Replace Driver. Qualcomm's QFIL then no longer sees the device until you
        reinstall its driver.
    • 
    

    
Linux

    
    
      
  • Let your user open the devices: create /etc/udev/rules.d/51-freeabl.rules with
        
    SUBSYSTEM=="usb", ATTR{idVendor}=="05c6", ATTR{idProduct}=="9008", MODE="0666"
SUBSYSTEM=="usb", ATTR{idVendor}=="18d1", MODE="0666"
    
        then sudo udevadm control --reload and reconnect the device.
    • 
      
  • Close the adb server first (adb kill-server): it holds devices in fastboot mode.
    • 
      
  • EDL: the kernel's qcserial driver takes the device first. Unload it while you flash:
        sudo modprobe -r qcserial.
    •
